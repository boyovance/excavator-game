### 人工驗收固定存檔

`npm run demo:manual` 會先核對打包 EXE 和 asar 是否與通過 `npm run test:exe` 的檔案完全一致，再啟動 `artifacts/release/manual-profile`。這是持續保留的隔離存檔，名稱初始為「M5獨立驗收」；重跑不覆蓋進度，不讀寫正式 `%APPDATA%/excavator-game`，沒有快轉或偵錯入口。由托盤打開車庫／退出。不需再次安裝。若重新打包，必須重新跑 EXE 測試後才可用。

下次使用者方便時配合一次真實短測（本輪不自動觸發睡眠）：

1. 開固定驗收存檔，派遣廢料場，記下開始時金幣與倒數；先不要領取。
2. 用 Windows 選單手動睡眠，約 5 分鐘後喚醒。觀察挖掘機位置、工作是否顯示待領取，是否出現完成通知（系統勿擾可能攔截）。
3. 點通知或從托盤打開車庫，領取一次，記下金幣與結果；從托盤退出，再執行同一命令重開，確認結果保存且不可重複領取。
4. 回報是否通過；若不符，提供畫面與操作步驟。通知／勿擾、拖曳邊緣、縮放後的觀感再依實際設備分項確認，不要求現在連續完成所有人工項。
